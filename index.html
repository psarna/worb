worb

GitHub

A single-process, open-source wandb-compatible server.

go install github.com/psarna/worb@latest && worb

Quick Install

Go
go install github.com/psarna/worb@latest
From source
git clone https://github.com/psarna/worb.git
cd worb && go build .
Docker
docker run -v ~/.worb:/data -p 8080:8080 \
  ghcr.io/psarna/worb --data /data
Then run it
./worb # starts on http://localhost:8080
import os
import wandb

os.environ["WANDB_DIR"] = "worb"
os.environ["WANDB_BASE_URL"] = "http://localhost:8080"
os.environ["WANDB_API_KEY"] = "dev-"+"lo"*20+"_example"

wandb.init(project="test-project", name="test-run")
for i in range(100):
    wandb.log({"loss": 1.0 / (i + 1), "step": i})
wandb.finish()
